# The two JS mirrors are enforced, not asked for

> Evidence for the `the-two-js-mirrors-are-enforced-not` row in [docs/STATE.md](../STATE.md) (What has worked).
> Text preserved verbatim from SCOREBOARD.md at the 2026-08-26 split.

**Trap T06 again, found before it bit.** `court.js` and `calls.js` are hand-copies of `court.py` and `calibration.py`, and both were guarded by a comment reading *"keep these in sync"* and by nothing else — the frontend has **no test runner**, so there was no side the check could run from. The failure mode is silent: correct a number in Python, every backend test passes, and the dashboard keeps showing the old value to the user. `tests/test_js_mirror_parity.py` reads the JS as text from the Python side (no Node, no new toolchain), **evaluates its arithmetic** so derived constants like `NET_Y` and `ALLEY` are compared as values rather than as source strings, and cross-checks `expected_call_accuracy` against the table the BROWSER holds at every knot plus both clamp ends. **The guards were proved to fail**: corrupting `LENGTH` 23.77 -> 23.78, one table row, and the floor 56.2 -> 50.0 each turned the suite red, and the files restored byte-identical. Also pins the court constants against **regulation** (23.77 / 10.97 / 8.23 / 6.40), because the mirror could agree and both be wrong. 6 tests, 381 total | 2026-08-15
